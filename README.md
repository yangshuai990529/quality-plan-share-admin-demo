# 画质方案分享管理 Demo

当前目录原本为空，本 Demo 根据提供的「用户反馈管理系统」后台截图创建了一个可直接打开的静态页面。

## 运行

```bash
python3 -m http.server 4180
```

然后访问 `http://127.0.0.1:4180/`。

## 已实现

- 左侧导航、顶部栏、查询区域、表格、字体、颜色和按钮风格沿用参考后台。
- 一级菜单「画质方案分享管理」。
- 用户列表：一行一个用户，支持 Client Type、机型、更新时间筛选。
- 用户方案详情：展示该用户全部方案及每个方案独立的分享码、信源、信号类型、图效、分享状态、创建时间、查询次数和保存使用次数。
- 单个方案详情：基础信息展示方案名称、分享码、创建时间、信源、信号类型、使用图效和分享状态；下方展示完整画质参数快照。
- 画质参数按参考图展示亮度、色彩、运动、清晰度、白平衡、色彩空间、其他七组；白平衡包含 2 点增益/偏差和 20 点（0–19 档）RGB 矩阵，色彩空间包含六色 RGB 值。
- 支持「用户列表 → 用户方案详情 → 单个方案详情」层级跳转和返回。

示例数据位于 `/Users/eric/Downloads/Codex Y/画质参数分享云端/app.js`，后续可替换为真实接口数据。

> 公开 Demo 中的用户、设备和分享码均为虚构示例数据，不对应真实用户或设备。

## 参数示例与验证

- 参数名称、值和分组顺序来自本次提供的完整画质设置参数截图；保留后台白色风格，以五列参数、20 点白平衡矩阵和三列色彩空间布局展示。
- 所有演示方案目前共用这份只读示例参数，尚未接入真实电视或云端方案快照接口。
- 较窄窗口下，20 点白平衡矩阵支持局部横向滚动，不省略档位。
- 验证命令：`node --check app.js && node --test tests/picture-params.test.cjs && git diff --check`。
