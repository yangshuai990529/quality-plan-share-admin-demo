# 画质方案分享管理 Demo

当前目录原本为空，本 Demo 根据提供的「用户反馈管理系统」后台截图创建了一个可直接打开的静态页面。

## 运行

```bash
python3 -m http.server 4180
```

然后访问 `http://127.0.0.1:4180/`。

## 已实现

- 左侧导航、顶部栏、查询区域、表格、字体、颜色和按钮风格沿用参考后台。
- 一级菜单「画质方案分享管理」。
- 用户列表：一行一个用户，支持用户 ID、设备 ID、机型、方案数量、更新时间筛选。
- 用户方案详情：展示该用户全部方案及每个方案独立的分享码、状态和使用次数。
- 单个方案详情：展示基础信息、七组画质参数快照及分享码使用记录。
- 支持「用户列表 → 用户方案详情 → 单个方案详情 → 使用记录」层级跳转和返回。

示例数据位于 `/Users/eric/Downloads/Codex Y/画质参数分享云端/app.js`，后续可替换为真实接口数据。

> 公开 Demo 中的用户、设备、分享码和使用记录均为虚构示例数据，不对应真实用户或设备。
